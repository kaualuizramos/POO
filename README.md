# 📚 POO - Programação Orientada a Objetos

## 📌 Sobre
Este repositório contém exercícios e práticas desenvolvidas durante os estudos de **Programação Orientada a Objetos (POO)**.

O objetivo é aplicar na prática os conceitos fundamentais da orientação a objetos utilizando código.

## 🎯 Objetivo
- Aprender os fundamentos da POO  
- Praticar a criação de classes e objetos  
- Desenvolver lógica de programação  
- Entender como organizar melhor o código  

## 🧠 Conteúdos trabalhados
- Classes e Objetos  
- Métodos e Atributos  
- Encapsulamento  
- Herança  
- Polimorfismo  

## 🛠️ Tecnologias
- Linguagem: **Java**

## 📖 Observações
Este repositório tem fins educacionais e faz parte do processo de aprendizado em programação.
